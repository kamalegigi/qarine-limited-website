# QARINE LIMITED Website - Quick Start (5 Minutes)

## ⚡ Super Fast Setup

### Step 1: Run Locally (2 min)
```bash
pnpm install
pnpm dev
```
Open: **http://localhost:3000**

### Step 2: Deploy to Vercel (2 min)
1. Push code to GitHub (if not already)
2. Go to **vercel.com**
3. Click **"Add New Project"**
4. Select your repo
5. Click **"Deploy"**
6. ✅ Live in minutes with HTTPS!

### Step 3: Set Custom Domain (1 min)
1. Buy domain (GoDaddy, Namecheap, etc.)
2. Point nameservers to Vercel
3. ✅ Done!

## 🔧 Make Changes

### Change Company Info
Edit: `components/contact.tsx` and `components/footer.tsx`

### Change Colors
Edit: `app/globals.css` (search for `--primary`)

### Add New Images
1. Drop PNG in `public/` folder
2. Update `components/products.tsx`

### Add New Section
1. Create `components/new-section.tsx`
2. Import in `app/page.tsx`
3. Add to JSX
